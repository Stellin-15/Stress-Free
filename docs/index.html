FAQ

Windows showed a SmartScreen warning — is it safe?

Yes. The warning appears because the installer isn't signed with a paid code-signing certificate. Click "More info" then "Run anyway" to proceed. The full source code is on GitHub so you can verify exactly what it does.

What are the system requirements?

Windows 10 or Windows 11 (64-bit). No additional software or Python installation needed — everything is bundled in the installer.

Does it need admin rights?

The installer requests admin access during setup (standard for Program Files installs). The app itself runs normally after that.

Will it interfere with my work?

The app stays on top and is easy to stop at any time — press ESC or click the Stop button. The ESC shortcut only works when the Orbit window is focused.

How do I uninstall it?

Use Add or Remove Programs in Windows Settings and search for "Orbit Mouse Pro". A full uninstaller is included.

How do I get updates?

The app checks for updates automatically on launch and shows a banner when a new version is available. You can also check this page — the version badge always shows the latest release.
