// FEATURES

◌

STEALTH MODE

Stays active with zero visible cursor movement. Watch a video, read, step away. Nobody sees a thing.

⏸

AUTO-PAUSE

Grab the mouse or hit a key and Orbit backs off instantly. It resumes once you've been idle for 15 seconds.

◉

REAL ACTIVITY

Moves are sent as genuine input, so they reset the Windows idle timer. Sleep and screen-off are blocked while running.

◎

MOVEMENT PATTERNS

Circle, Figure-8 or Jitter, with radius and speed sliders that update live.

⌨

GLOBAL HOTKEYS

Ctrl+Alt+H hides or shows the window and Ctrl+Alt+O starts or stops it, from any app.

◱

LIVES IN THE TRAY

Closing the window keeps Orbit running quietly in the tray, and it remembers your settings.

⏱

LIVE IDLE READOUT

See exactly what Windows sees: SYS IDLE stays near zero while Orbit works.

📈

PRODUCTIVITY SCORE

A completely fake % that climbs while running. Caps at 99%. Never hits 100.

// FAQ

Windows showed a SmartScreen warning — is it safe?

Yes. The warning appears because the installer isn't signed with a paid certificate. Click More info then Run anyway. The full source code is on GitHub — verify exactly what it does.

What are the system requirements?

Windows 10 or Windows 11 (64-bit). No Python or additional software needed — everything is bundled in the installer.

Does it need admin rights?

The installer requests admin access during setup (standard for Program Files installs). The app itself runs normally after that.

Will it keep me "Available" in Teams or Slack?

Teams, Slack and Windows itself decide you're away from the system idle timer. Orbit sends real input events that reset it, and the SYS IDLE readout shows the timer live. Older versions (v1.1.0 and earlier) only moved the cursor, which doesn't count, so please update.

Will it interfere with my work?

No. With Auto-pause on (the default), Orbit stops the moment you move the mouse or press a key, and resumes after 15 seconds of idle. Stealth mode never moves the cursor at all. Ctrl+Alt+O stops it from any app.

How do I uninstall it?

Open Add or Remove Programs in Windows Settings and search for "Orbit Mouse Pro". A full uninstaller is included.

How do I get updates?

The app checks for updates on launch and shows a notice in its footer when a new version is out. Every release is listed on the Releases page with a SHA-256 checksum.
